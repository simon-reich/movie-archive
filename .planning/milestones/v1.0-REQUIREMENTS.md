## v1 Requirements — Final Status

### Authentication ✅ Complete

- [x] **AUTH-01**: User kann Account mit E-Mail + Passwort erstellen — Phase 1, validated
- [x] **AUTH-02**: User erhält Verifizierungs-E-Mail nach Sign-Up; Account wird erst nach Klick aktiviert — Phase 1, validated
- [x] **AUTH-03**: User kann sich mit E-Mail + Passwort einloggen (nur ACTIVE-Accounts) — Phase 1, validated
- [x] **AUTH-04**: User erhält JWT Access Token (15 min) + Refresh Token als HttpOnly-Cookie (7 Tage) — Phase 1, validated
- [x] **AUTH-05**: Refresh Token wird bei /auth/refresh rotiert (altes revoked, neues ausgestellt) — Phase 1, validated
- [x] **AUTH-06**: User kann sich ausloggen (Refresh Token wird revoked) — Phase 1, validated
- [x] **AUTH-07**: User kann Passwort-Reset per E-Mail anfordern (immer 200 OK — Enumeration-Schutz) — Phase 1, validated
- [x] **AUTH-08**: User kann Passwort mit Token zurücksetzen; alle Refresh Tokens des Accounts werden revoked — Phase 1, validated

### Settings ✅ Core Complete (CSV deferred to v2)

- [x] **SET-01**: User kann TMDB API-Key speichern und ändern (AES-256-GCM verschlüsselt, Anzeige immer maskiert) — Phase 2, validated
- [x] **SET-02**: User kann OMDB API-Key speichern und ändern (optional, gleiche Verschlüsselung) — Phase 2, validated
- [x] **SET-03**: User kann Passwort ändern (erfordert aktuelles Passwort; revoked alle Refresh Tokens) — Phase 2, validated
- [x] **SET-04**: User kann E-Mail-Adresse ändern (Token-Link an neue Adresse; alte Adresse wird informiert) — Phase 2, validated
- [ ] **SET-05**: User kann alle Filmdaten als CSV exportieren — **DEFERRED to v2** (UI placeholder only)
- [ ] **SET-06**: User kann Filmdaten aus einer CSV-Datei importieren — **DEFERRED to v2** (UI placeholder only)

### Save Movie Flow ✅ Complete

- [x] **SAVE-01**: User kann Film via TMDB-Suche oder direkt per TMDB-ID zur Sammlung hinzufügen → sofort 202 Accepted — Phase 3, validated
- [x] **SAVE-02**: Backend reichert Film async an: TMDB → OMDB (optional) → Wikipedia → Postgres → OpenSearch — Phase 3, validated
- [x] **SAVE-03**: OMDB-Anreicherung schlägt graceful fehl wenn kein Key konfiguriert oder kein imdb_id in TMDB-Antwort — Phase 3, validated
- [x] **SAVE-04**: Wikipedia-Anreicherung schlägt graceful fehl (6-Step-Fallback); Film wird immer gespeichert — Phase 3, validated
- [x] **SAVE-05**: UI zeigt Save-Status sichtbar an (pending → success / error) — kein silent failure — Phase 3, validated

### OpenSearch Indexing ✅ Complete

- [x] **IDX-01**: Film-Daten werden nach Postgres-Persist in OpenSearch-Index `movies-{userId}` indexiert — Phase 4, validated
- [x] **IDX-02**: Index wird bei erstem Film eines Users automatisch mit Custom Analyzer und finalem Mapping erstellt — Phase 4, validated
- [x] **IDX-03**: Custom Analyzer: asciifolding, lowercase, elision, stop_english, kstem — Phase 4, validated
- [x] **IDX-04**: Admin-Endpoint zum Neuaufbau des Index eines Users (`POST /admin/reindex/{userId}`) — Phase 4, validated

### Search ✅ Complete

- [x] **SRCH-01**: User kann Freitext-Suche über alle indizierten Film-Felder durchführen — Phase 5, validated
- [x] **SRCH-02**: User kann Advanced Filters kombinieren: Genre, Regisseur, Jahr, IMDB-Rating, Content-Rating, Watched — Phase 5, validated
- [x] **SRCH-03**: User kann Suchergebnisse sortieren (Titel A–Z, Jahr, persönliches Rating, IMDB-Rating) — Phase 5, validated
- [x] **SRCH-04**: Klick auf Namen / Attribut (Schauspieler, Regisseur, Genre etc.) öffnet vorgefilterte Suche — Phase 5, validated

### Movie Detail ✅ Complete

- [x] **DETAIL-01**: Film-Detailseite zeigt alle TMDB + OMDB Felder (nullable OMDB-Felder werden ausgeblendet) — Phase 6, validated
- [x] **DETAIL-02**: Film-Detailseite zeigt Wikipedia Plot und Critics-Section (falls vorhanden) — Phase 6, validated
- [x] **DETAIL-03**: User kann persönliche Felder setzen: Watched-Status, Rating (0–10), Notizen (Freitext, indiziert) — Phase 6, validated
- [x] **DETAIL-04**: Film-Detailseite zeigt Trailer als YouTube-Embed (via TMDB trailer_key, falls vorhanden) — Phase 6, validated
- [x] **DETAIL-05**: Klick auf Schauspieler / Regisseur / Genre etc. öffnet gefilterte Suchergebnisliste — Phase 6, validated

### Polish & Quality ✅ Complete

- [x] **QLTY-01**: App ist responsive und auf Mobilgeräten vollständig nutzbar — Phase 7, validated
- [x] **QLTY-02**: E2E-Tests mit Playwright (Happy Paths: Sign-Up → Film speichern → suchen → Detail) — Phase 7, validated
- [x] **QLTY-03**: README mit Setup-Anleitung und Feature-Übersicht — Phase 7, validated
