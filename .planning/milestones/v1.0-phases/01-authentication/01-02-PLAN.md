**Why this fix is required:**

Caddy's `reverse_proxy` does NOT strip path prefixes by default. Without `uri strip_prefix /api`, the browser calls `POST /api/auth/login` and Spring Boot receives `POST /api/auth/login`. But Spring Boot's `AuthController` is mapped to `/auth/**` (not `/api/auth/**`) and `SecurityConfig.permitAll()` permits `/auth/**` (not `/api/auth/**`). The result is that every auth request hits a 404 or 403 from Spring Boot.

Adding `uri strip_prefix /api` inside the `handle /api/*` block makes Caddy strip the prefix before forwarding. The browser calls `/api/auth/login`, Caddy strips `/api`, Spring Boot receives `/auth/login` — which matches the controller mapping.

**Cookie path consequence (handled in Tasks 1 and 3):**

The `Set-Cookie` response from Spring Boot sets `path=/api/auth/refresh`. The browser stores the cookie with that path. When the browser later calls `POST /api/auth/refresh`, it checks: does `/api/auth/refresh` start with `/api/auth/refresh`? YES — cookie is sent. This is why all `ResponseCookie.from(...)` calls must use `path("/api/auth/refresh")` (not `path("/auth/refresh")`).

**The fix:**

Replace the `handle /api/*` block in `Caddyfile` with:

```
handle /api/* {
    uri strip_prefix /api
    reverse_proxy backend:8080 {
        header_up X-Forwarded-Proto {scheme}
        header_up X-Real-IP {remote_host}
    }
}
```

Do NOT modify any other block in the Caddyfile.

**Step 4 — Create TokenUtils** (package de.moviearchive.auth):
```java
package de.moviearchive.auth;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.HexFormat;

public final class TokenUtils {
    private TokenUtils() {}

    public static String hashToken(String rawToken) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            byte[] hash = digest.digest(rawToken.getBytes(StandardCharsets.UTF_8));
            return HexFormat.of().formatHex(hash);
        } catch (NoSuchAlgorithmException e) {
            throw new IllegalStateException("SHA-256 not available", e);
        }
    }
}
```

public SecurityFilterChain filterChain(HttpSecurity http, JwtService jwtService,
                                       UserDetailsServiceImpl userDetailsService) throws Exception {
    JwtAuthFilter jwtAuthFilter = new JwtAuthFilter(jwtService, userDetailsService);
    http

Also inject `@Value("${jwt.refresh-token-expiration-ms}") long refreshTokenExpirationMs`.

Implement these methods:

`signup(SignupRequest req)`:
- Check userRepository.existsByEmail(req.email()) → throw EmailAlreadyExistsException if true
- Create User(req.email(), passwordEncoder.encode(req.password())) and save
- Generate rawToken = UUID.randomUUID().toString(), hash it, save EmailVerificationToken(user, hash, Instant.now().plus(24, ChronoUnit.HOURS))
- Call mailService.sendVerificationEmail(req.email(), rawToken)

`verifyEmail(String rawToken)`:
- hash = TokenUtils.hashToken(rawToken)
- token = emailVerificationTokenRepository.findByTokenHash(hash) → throw TokenNotFoundException if empty
- If token.isExpired() → throw TokenExpiredException
- If token.isConsumed() → throw TokenAlreadyConsumedException
- token.setConsumedAt(Instant.now()); save; token.getUser().setStatus(UserStatus.ACTIVE); save user

`resendVerification(String email)`:
- Find user by email; if not found or ACTIVE, return silently (always 200)
- Delete existing unused tokens, create new token, send verification email

`login(LoginRequest req, HttpServletResponse response)`:
- Find user by email → throw BadCredentialsException("Invalid email or password") if not found (same message for both cases — no enumeration)
- If status != ACTIVE → throw AccountNotActiveException
- If !passwordEncoder.matches(req.password(), user.getPasswordHash()) → throw BadCredentialsException("Invalid email or password")
- Generate access token via jwtService.generateAccessToken(user)
- Generate rawRefresh = UUID.randomUUID().toString(), hash it
- Save RefreshToken(user, hash, Instant.now().plus(refreshTokenExpirationMs, ChronoUnit.MILLIS))
- Build cookie: ResponseCookie.from("refresh_token", rawRefresh).httpOnly(true).secure(true).sameSite("Strict").maxAge(Duration.ofMillis(refreshTokenExpirationMs)).path("/api/auth/refresh").build()
  NOTE: path is "/api/auth/refresh" — this is the browser-visible URL after Caddy routing. Task 0 adds `uri strip_prefix /api` to Caddy so Spring Boot still maps /auth/refresh, but the cookie scope must match what the browser calls.
- response.addHeader(HttpHeaders.SET_COOKIE, cookie.toValueString())
- Return LoginResponse(accessToken, user.getEmail())

`refresh(String rawRefreshToken, HttpServletResponse response)`:
- hash = TokenUtils.hashToken(rawRefreshToken)
- token = refreshTokenRepository.findValidToken(hash, Instant.now()) → throw TokenNotFoundException if empty
- If token.isExpired() → revoke it, throw TokenExpiredException
- Set token.revoked=true, token.graceUntil=Instant.now().plusSeconds(5); save (grace window)
- Generate new access token, create new RefreshToken (same user), issue new cookie (same cookie settings — path("/api/auth/refresh"))
- Return RefreshResponse(newAccessToken, token.getUser().getEmail())

`logout(String rawRefreshToken)`:
- hash = TokenUtils.hashToken(rawRefreshToken)
- token = refreshTokenRepository.findByTokenHash(hash) → if empty, return silently
- token.setRevoked(true); save

`forgotPassword(String email)`:
- ALWAYS return normally regardless of whether email exists (enumeration protection)
- If user found and ACTIVE: generate rawToken, hash, save PasswordResetToken(user, hash, Instant.now().plus(1, ChronoUnit.HOURS)); send reset email
- Log at debug level if not found

`resetPassword(String rawToken, String newPassword)`:
- hash = TokenUtils.hashToken(rawToken)
- token = passwordResetTokenRepository.findByTokenHash(hash) → throw TokenNotFoundException if empty
- If token.isExpired() → throw TokenExpiredException
- If token.isConsumed() → throw TokenAlreadyConsumedException
- token.setConsumedAt(Instant.now()); save
- user.setPasswordHash(passwordEncoder.encode(newPassword)); save
- refreshTokenRepository.revokeAllByUserId(user.getId())

`me(Authentication authentication)`:
- Return Map.of("email", authentication.getName()) or a simple record
