<objective>
Close UAT gap G-10-1: the Bulk Import section on the Add Film page gives no format guidance
and the UI shows "Import started. This runs in the background." unconditionally, so a batch
where every line fails to parse (e.g. plain movie titles with no semicolons, instead of the
required `Title;OriginalTitle;Year` format) looks identical to a fully successful import. The
backend pipeline itself is correct per spec (D-01/D-03) — this is a UX/discoverability gap, not
a backend defect.

Purpose: Give the user (1) a visible hint of the required format before they upload, and (2) a
specific, synchronous 400 response — instead of a silent async no-op — when a batch is wholly
unparseable, so a 100%-failed import is never indistinguishable from a success.
Output: A pre-flight parse-validity gate in `BulkImportController`, and a format hint plus
backend-message surfacing in `add.vue`.
</objective>
