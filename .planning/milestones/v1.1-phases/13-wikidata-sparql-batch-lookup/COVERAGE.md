No external API integration: this phase reuses the existing Wikidata/Wikipedia integration surface established in Phase 12 (a single capability — IMDb-ID to enwiki-article-title resolution) and only changes the underlying transport/protocol for that one capability from two REST calls (CirrusSearch search + REST sitelinks against `www.wikidata.org`) to one batched SPARQL query (against the distinct host `query.wikidata.org`). No new external API, SDK, or service surface is added, and no new capability is introduced — the AI-integration API-coverage matrix does not apply.
