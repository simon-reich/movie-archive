## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Browser -> `GET /admin/wiki-reload/{userId}/progress` | Untrusted client opens a long-lived SSE stream identified by a client-supplied `userId` path variable |
| Browser -> `POST /admin/wiki-reload/{userId}/stop` | Untrusted client requests cancellation of an in-progress batch identified by a client-supplied `userId` path variable |
| Async batch loop <-> `WikiReloadProgressService` in-memory registry | Cross-thread state shared between the `wikiReloadExecutor` worker thread and HTTP request threads |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01 | Elevation of Privilege | `GET .../progress`, `POST .../stop` (WikiReloadController) | high | mitigate | Both new endpoints call the existing `assertOwnership(auth, userId)` private method (already proven correct by the passing `shouldReturn403_whenUserMismatch` test on `triggerReload`); Task 2 adds the identical 403 regression test for both new endpoints |
