<objective>
Add the two admin reindex endpoints and their IndexingService backing methods, with JWT-subject ownership enforcement (D-03), then enable and implement the ReindexControllerTest cases for IDX-04.

Purpose: D-01 makes OpenSearch write failures silent, so the system needs an explicit recovery path. The two-speed reindex design (D-04) provides it: a full rebuild for mapping/analyzer drift and a partial load for films that failed to index during save. Both are user-scoped and ownership-protected.

Output: IndexingService.fullReindex + reindexPending, ReindexController (2 endpoints + 403 handler), ReindexControllerTest implemented.
</objective>
