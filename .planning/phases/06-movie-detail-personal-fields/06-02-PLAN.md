```java
/**
 * Removes the OpenSearch document for a movie. Swallows document-missing errors
 * because the movie may not have been indexed yet (indexed_at = null).
 */
public void deleteDocument(String indexName, UUID movieId) throws IOException {
    try {
        client.delete(DeleteRequest.of(r -> r
            .index(indexName)
            .id(movieId.toString())));
        log.info("Deleted OS document movieId={} from index={}", movieId, indexName);
    } catch (Exception e) {
        // Swallow — document may not exist (never indexed), or index may not exist
        log.warn("OS delete failed (document may not exist) movieId={}: {}", movieId, e.getMessage());
    }
}
```

```java
// Dependency injection — add to constructor:
// private final IndexingService indexingService;
// Add IndexingService to the @RequiredArgsConstructor fields

public void updatePersonal(UUID userId, UUID movieId, Map<String, Object> fields) {
    Movie movie = movieRepository.findByIdAndUserId(movieId, userId)
            .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "Movie not found"));

    if (fields.containsKey("watched")) {
        Object val = fields.get("watched");
        movie.setWatched(val instanceof Boolean b ? b : Boolean.valueOf(String.valueOf(val)));
    }
    if (fields.containsKey("personalRating")) {
        Object val = fields.get("personalRating");
        if (val == null) {
            movie.setPersonalRating(null);
        } else {
            // Jackson deserializes integers as Integer — convert to Short
            movie.setPersonalRating(val instanceof Number n ? n.shortValue() : null);
        }
    }
    if (fields.containsKey("personalNotes")) {
        Object val = fields.get("personalNotes");
        movie.setPersonalNotes(val instanceof String s ? s : null);
    }

    movieRepository.save(movie);

    // Sync to OpenSearch — full re-index (proven pattern, no UpdateRequest API uncertainty)
    if (movie.getIndexedAt() != null) {
        try {
            String indexName = "movies-" + userId;
            indexingService.ensureIndexExists(indexName);
            indexingService.index(movie);
        } catch (IOException e) {
            log.warn("OS sync failed for personal update movieId={}: {}", movieId, e.getMessage());
            // Silent fail — Postgres is source of truth
        }
    }
}

public void deleteMovie(UUID userId, UUID movieId) {
    Movie movie = movieRepository.findByIdAndUserId(movieId, userId)
            .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "Movie not found"));

    // Remove from OpenSearch first (idempotent — swallows not-found)
    try {
        String indexName = "movies-" + userId;
        indexingService.deleteDocument(indexName, movieId);
    } catch (IOException e) {
        log.warn("OS delete failed for movieId={}: {}", movieId, e.getMessage());
        // Continue with Postgres delete regardless
    }

    movieRepository.deleteById(movieId);
    log.info("Deleted movie movieId={} for userId={}", movieId, userId);
}
```

| Boundary | Description |
|----------|-------------|
| Client → PATCH /movies/{id}/personal | Authenticated; movieId in path is user-supplied; request body is free-form JSON |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02-01 | Tampering / Info Disclosure | PATCH /movies/{id}/personal IDOR | mitigate | `findByIdAndUserId(movieId, userId)` in updatePersonal() — same dual-key ownership check as GET. Returns 404 to avoid leaking existence of other users' movies. |
| T-06-02-02 | Tampering | DELETE /movies/{id} IDOR | mitigate | `findByIdAndUserId(movieId, userId)` in deleteMovie() before any deletion. OS delete happens after ownership is confirmed. Postgres delete is the final step. |
| T-06-02-03 | Tampering | PATCH body — mass assignment | mitigate | PATCH uses `Map<String, Object>` with explicit `containsKey` checks. Only three allowed keys (watched, personalRating, personalNotes) are ever read — no other movie fields can be overwritten. userId is never in the map. |
| T-06-02-04 | Tampering | personalNotes injection | accept | personalNotes is stored as plaintext TEXT in Postgres. Vue/Nuxt auto-escapes `{{ }}` interpolation — no v-html on user data. Server-side: plaintext stored, no HTML processing. Acceptable for single-user personal app. |
| T-06-02-05 | Denial of Service | PATCH notes field length | accept | No explicit length limit on personalNotes. Postgres TEXT is unbounded. Acceptable for personal single-user app (user is harming only themselves). Add limit in Phase 7 if needed. |
