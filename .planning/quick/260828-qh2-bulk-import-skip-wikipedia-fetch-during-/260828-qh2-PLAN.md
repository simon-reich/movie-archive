<objective>
Stop bulk import from fetching Wikipedia per movie. Bulk-imported movies should get TMDB + OMDB data only during the import run; `WikiReloadService.batchReload()` backfills their Wikipedia data later, paced and outside the synchronous bulk-import dispatch loop.

Purpose: bulk import currently runs the full TMDB->OMDB->Wikipedia pipeline for every matched line, which pushes a ~1000-movie import to take up to a day. Wikipedia's 6-step/10-candidate fallback cascade is the slow, rate-limit-prone part; skipping it during import — and relying on the existing, already-paced `WikiReloadService.batchReload()` job to fill it in afterward — is the fix.
Output: `EnrichmentService.enrich(UUID, boolean skipWikipedia)` overload that skips Step 3 (Wikipedia) entirely when true; `BulkImportService`'s Pass 2 uses it; the now-consumerless Wikidata SPARQL batch prefetch (Pass 1.5) and its Pass-1 imdbId-prefetch step are removed since they existed only to feed that Wikipedia step.
</objective>
